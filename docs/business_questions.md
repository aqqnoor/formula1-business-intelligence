# 6. Операционализация бизнес-вопросов

## Цель

Бизнес-вопросы, сформулированные в техническом задании, содержат абстрактные понятия (например, *«успешный этап»*, *«конкурентная трасса»*, *«стабильный пилот»*). Перед разработкой SQL-запросов необходимо определить, как эти понятия будут измеряться с помощью данных.

Для каждого вопроса определяются:

* интерпретация;
* ключевые показатели эффективности (KPI);
* необходимые таблицы базы данных;
* ожидаемый аналитический результат.

## Почему это выглядит профессионально

Такой документ выглядит как артефакт настоящего аналитического проекта. Он показывает, что ты не просто написала SQL-запросы, а прошла полный путь:

**Бизнес-задача → Интерпретация → KPI → SQL → Дашборд**

Именно по такой логике строится работа BI- и Data-аналитиков в компаниях. После этого документа написание SQL становится естественным следующим этапом, потому что для каждого KPI уже понятно, какие данные нужны и что именно нужно рассчитать.
